What changed, and why?

The strongest single-responsibility improvement in v2 is the dedicated display.js module. It keeps rendering separate from keyboard handling and timer management. V2’s engine also documents itself as pure state and returns a copied visible board, reinforcing the engine/render boundary.

V1 has broader automated terminal coverage and a narrower minimum width. V2 provides richer controls and a more configurable engine. Because the v2 plan contains no recorded findings, these differences should be treated as normal generation variance rather than demonstrated effects of validation.
